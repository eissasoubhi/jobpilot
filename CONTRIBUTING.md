# Contributing to JobPilot

Thanks for your interest in improving JobPilot's public site.

## Scope of this repository

This repository contains the public-facing JobPilot website and documentation. The main application code and private user data are maintained separately.

Good contributions include:

- improving accessibility, semantics, SEO, or responsive behavior;
- fixing broken links, typos, or unclear documentation;
- improving the public site's performance and maintainability;
- keeping privacy and security documentation accurate.

## Before opening a pull request

1. Keep changes focused and easy to review.
2. Do not commit API keys, tokens, `.env` files, CVs, email content, application data, or other personal information.
3. Verify that public pages still work as static files on GitHub Pages.
4. Explain what changed and why in the pull request description.

## Pull requests

Use a short, descriptive title and keep unrelated changes in separate pull requests. For visual changes, include a short description of the expected result.

By contributing, you agree that your contribution may be published as part of this public repository under the repository's applicable license and terms.
